# Setup brief for a fresh local work agent

Read README.md, then docs/replication-checklist.md and the relevant runbook before configuring this computer.

Use one work-only default profile for this computer's desktop, CLI and Slack bot. Do not create another profile merely to add Slack. Each computer gets a unique Slack app/token pair; never connect a PC or copy its live state because a historical skill mentions it.

Credentials and OAuth remain local to the chosen profile. Non-secret settings use hermes config set. A repository clone does not automatically install skills, share memory, or authenticate MCPs. Preserve useful curated work skills; exclude personal context and private work asset registries from Git.

Distinguish configuration, tool discovery, live app/account access and a completed artifact. Exercise real read-only tools before claiming readiness. Stop for user login, MFA and OAuth/workspace consent; never ask for tokens in chat or print them.

Open Slack with terminal/desktop tools is not sandboxed by profile names or prompt rules. Review privacy-and-separation before allowing everyone. Use local application control on the computer that owns the app.

The repeatable helper scripts are optional and have explicit scope. Do not overwrite project/startup files during connectivity setup. Follow the actual installed CLI/help when versioned documentation differs. Publish only reviewed secret-free instructions and code.
