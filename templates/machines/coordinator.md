# Coordinator machine brief

Role: intake, routing, approvals, task-board maintenance, and final verification.

Setup: install Hermes, run `hermes setup` and `hermes doctor`, use the same work-only default profile for desktop, CLI, and Slack, then connect Slack and OAuth MCP only after local acceptance. Keep the coordinator workspace free of specialist caches and raw media.

Standing rules: never publish without acceptance criteria; never expose secrets; use Notion task IDs; ask specialist machines for artifact path and verification; keep Slack bot-to-bot mode off unless explicitly needed.
