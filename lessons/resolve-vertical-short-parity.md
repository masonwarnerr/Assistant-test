# Match a proved native keeper when rebuilding Resolve vertical shorts

Status: verified worker procedure from the DaVinci Mac, 2026-10-19.

- Scope: rebuilding or converting vertical Resolve shorts from complete horizontal or multicamera assemblies.
- Prerequisites: an accepted native vertical keeper, complete ordered source assemblies, prepared captions, and authorized program audio.
- Source: same-machine native readback, two corrective render batches, exact delivery inventory, and complete decode of 21 final MP4s.

A 1080×1920 timeline and `SmartReframe() == True` do not prove that picture fills 9:16. A render can be a vertical container with horizontal picture fitted inside it. Read the accepted keeper’s native state and match it: set timeline mismatch behavior to `scaleToCrop`, set every enabled picture item to the keeper’s fill value (`Scaling == 3` in the verified build), then call Smart Reframe on each enabled picture item and read the property back.

Rebuild the whole short assembly in record order. Do not export only the first range of a multi-range selection. Copy the proved keeper grade to each picture item and verify its node/tool structure. Retain or import the prepared Fusion caption comp, keep only the authorized enhanced program track enabled, and leave alternate camera audio disabled rather than substituting it.

If creating a new timeline hangs after identity creation, do not replay non-idempotent initialization. Reconcile the partial state. When a complete assembly timeline already exists, convert that timeline in place in a new revision instead of creating a duplicate. A zero-frame named timeline or an initialization-only ledger is not a completed short.

Render one short at a time to local disk, require stable size and a complete decode, then copy the proved file to the authorized delivery folder. Inspect rendered frames against the keeper; API success and container dimensions are insufficient. The acceptance check is native `scaleToCrop`, keeper-equivalent per-item scaling, successful per-item reframing, grade/caption/program-audio parity, complete decode of every expected movie, and exact delivery inventory with rejected files absent.
