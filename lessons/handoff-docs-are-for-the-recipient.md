# Handoff docs are for the recipient

Status: face correction, repeated 2026-11-18. Intent only.

- Scope: a Notion or brief being handed to another person (a new designer, an editor, a partner).
- Source: mason, twice the same day, after a page came back full of notes to him.

Write the page to the person receiving it. Delete notes, flags, and TBDs addressed to Mason ("Mason to confirm", "skill file missing", "best guess", "open question for Mason"). Do not restore a section he already deleted. Do not add color coding he removed.

Child pages are a short bullet list of links on the parent. They are not a heading plus a summary for each one.

A work-scope category is defined in general terms. A specific project sits under that category as a sub-bullet. A content-menu deck is one deck task. It is not the definition of presentation decks.

Re-read the page after the edit. If a line is a note to Mason, it is not done.
