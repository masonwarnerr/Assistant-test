# Do not open a project another agent is using

- Scope: Resolve, any shared cloud library.
- Date: 2026-10-07
- Source: Mason, Victor shortform. Recorded in local skill `slash-davinci-edit`.

If he says another agent has the old project, leave it closed. Do not LoadProject it to copy a grade or grab a still.

Start from the project already current. A new Untitled is fine. Do not save over Untitled if that would clobber it. Grade from a PowerGrade already in the gallery.

If LoadProject already fired on the locked name, kill that Astra process and confirm the current project is not that name before continuing.

Check: current project is the new one. The locked project was not opened.
